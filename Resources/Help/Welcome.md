# Welcome to MdEdit

MdEdit renders markdown **where you type it**. Write `# ` at the start of a line and it becomes a heading; wrap words in `**` and they turn bold. Move the caret onto a line and its markdown comes back, so you can edit it.

## Try it here

This tab is an untitled copy, so change anything you like.

- [ ] Tick this box with a click
- [ ] Put the caret on this line: **its asterisks reappear**
- [ ] Press Return at the end of this item to start another, and Return again on the empty one to leave the list

> Quotes, `code`, ==highlights==, ~~strikethrough~~ and [links](https://github.com/msk-mdi/MDedit) all render as you type. ⌘-click a link to follow it.

| Shortcut | Does |
| :------- | :--- |
| ⌘B, ⌘I | Bold, italic |
| ⌘K | Link |
| ⌘/ | Source mode: plain markdown |
| ⌘P | Quick Open |
| ⇧⌘I | Statistics and word goal |

## Where things are

- **Format** inserts and toggles everything: headings, lists, tables, code blocks.
- **View** has the outline (⇧⌘L), files (⇧⌘E), typewriter and focus modes, and folding.
- **File ▸ Export** writes HTML, PDF, Word and more.
- **Help ▸ Markdown Cheat Sheet** lists every piece of syntax MdEdit understands.

Open a file (⌘O) or a folder (⇧⌘O) to get started. This page will not show again; it is always under **Help ▸ Welcome to MdEdit**.
